# Organización del repositorio

He dejado una estructura temática para facilitar la navegación del contenido:

- `python/` — Python y análisis con pandas
- `scala/` — Scala y notebooks
- `sql/` — SQL y ejercicios

## Recomendación final
Para una organización definitiva, conviene mover también los PDFs y las imágenes a sus carpetas respectivas y actualizar enlaces en los README de cada tema.
